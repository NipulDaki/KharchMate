# KharchMate
KharchMate is a simple and user-friendly personal finance app designed to help users track their income, expenses, and spending habits in one place.

The app focuses on a clean and intuitive experience for quickly recording daily transactions, monitoring financial activity, and understanding where money is being spent — without requiring external APIs.

Key Features
💰 Track income
💸 Track expenses
📊 View income vs. expense summaries
🧾 Add and manage transactions
📅 Track transactions by date
🏷️ Categorize expenses
📈 Basic spending insights
🔒 Local/offline data storage
🎨 Clean modern UI using the KharchMate orange theme

KharchMate — Track your money. Understand your spending. Take control.
